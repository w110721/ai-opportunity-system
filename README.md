# AI应用场景智能挖掘与机会评估系统

本项目为数睿思（BdRace）数据挖掘竞赛本科组A题参赛作品，面向产品决策与创业孵化场景，实现从多源公开文本中自动挖掘AI应用需求、量化评估落地价值的完整技术链路。

## 项目简介
针对当前AI应用需求分散在各类社区平台、难以系统挖掘与量化评估的问题，本系统构建了「多源采集-清洗降噪-智能识别-量化评估-可视化输出」的全流程方案。系统以哔哩哔哩为核心数据源，补充开源社区、技术博客、问答平台等多渠道文本，基于大语言模型完成真实需求抽取与三维度价值打分，最终输出可支撑产品决策与创业研判的结构化机会清单。

## 功能特性
- **多源数据采集**：以哔哩哔哩为核心，覆盖GitHub Issues、掘金、知乎四大公开渠道，支持多关键词定向搜索与自动去重
- **文本清洗降噪**：通过正则规则自动去除链接、代码块、冗余符号与低质量短文本，提升后续识别准确率
- **智能需求识别**：基于Prompt工程驱动大语言模型，从杂乱文本中判断是否包含真实业务痛点，并结构化抽取需求描述、所属行业、现存卡点、匹配AI能力等字段
- **三维量化评估**：从**需求强度、AI可行性、价值潜力**三个维度建立指标体系，加权计算综合机会得分，输出可量化的决策依据
- **交互式可视化系统**：基于Streamlit搭建Web界面，支持单条文本研判、批量数据评估、结果导出，配套雷达图直观展示打分维度

## 技术栈
- 编程语言：Python 3.9+
- 可视化界面：Streamlit
- 数据处理：Pandas
- 图表绘制：Plotly
- 网页采集：Requests + BeautifulSoup4
- 核心推理：兼容OpenAI接口规范的大语言模型API（默认对接DeepSeek）
